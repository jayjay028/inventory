1.2 Navigation & Layout

The interface offers both a light and a dark mode, toggled via the sun/moon button in the top header. The app remembers your preference across sessions (dark is the default). Both themes use the brand's blue-to-teal accent (matching the MaraCoder logo) on buttons, active menu items, and highlights, designed for comfortable extended use. The UI previews shown throughout this manual reflect the dark appearance.

The menu behaves like a full web application: every menu item is clickable and navigates instantly (no page reload). 2. Multi-Store System

2.1 Overview

The system now supports multiple stores / branches operating within a single system. This lets a business run several outlets while keeping each store's operations separate and its shared reference data consistent.

What is separate per store

Each store maintains its own independent:

  • Stock — Quantities on hand are tracked per store
  • Sales — POS sales belong to the store where they were made
  • Shifts — Cashier shifts are opened and closed per store
  • Document numbering — OR, SI, and DR sequences run independently for each store

What is shared across all stores

Master data is defined once and shared by every store:

  • Items
  • Categories
  • Customers
  • Suppliers
Users are granted access to specific stores. A user can only see and operate the stores they are assigned to.

2.2 Store Selection

After you log in, the store you work in is determined by your assigned store access:

  • If you have access to multiple stores, a Store Selection screen appears so you can choose which store to work in.
  • If you have access to only one store, it is auto-selected and you skip the selection screen.

Switching stores

The current store is shown in the top navbar alongside a Store Selector dropdown:

2.3 Super Administrator

  • User ID 1 — the initial admin account — is the Super Administrator.
  • The super admin has access to all stores automatically, including any newly created stores, without needing explicit assignment.
  • The super admin is responsible for granting store access and permissions to other users.

2.4 Default Landing Page

Where you land after login is determined automatically from your permissions — there is no separate setting to configure:

  • By default, all users land on the Dashboard.
  • Exception: a user who can use the POS terminal but does not have dashboard access lands directly on the POS terminal. This is ideal for cashiers.

8. Stock Operations

Stock Overview

Go to Inventory → Stock Overview (left sidebar) to see current stock levels.

Stock status indicators:

  • NORMAL — Quantity above reorder level
  • LOW — At or below reorder level
  • OUT OF STOCK — Zero quantity

8.1 Stock In (Receiving Goods)

Create Transaction → Status: CREATED → Approve → Stock Updated ✓
  1. Go to Inventory → Stock In (left sidebar)
  2. Select the Item (current stock shown)
  3. Enter Quantity and Unit Cost
  4. Optionally select a Supplier
  5. Choose Document Type (PO, RR, or None)
  6. Toggle Apply Tax if applicable
  7. Add Remarks and Add-ons (shipping, handling) if needed
  8. Click Submit
Stock is NOT updated immediately. The transaction must be Approved first.

8.2 Stock Out (Releasing Goods)

  1. Go to Inventory → Stock Out (left sidebar)
  2. Select the Item (validates sufficient stock)
  3. Enter Quantity and Unit Price
  4. Optionally select a Customer
  5. Apply Discount if applicable (Fixed or Percentage)
  6. Choose Document Type (OR, SI, DR, or None)
  7. Click Submit

8.3 Stock Adjustment

Use for physical count corrections or inventory adjustments.

  1. Go to Inventory → Stock Adjustment
  2. Select the Item
  3. Enter the correct Quantity
  4. Add a Reason/Remarks (required for audit)
  5. Click Submit

8.4 Transaction Approval

All stock transactions go through an approval workflow:

StatusMeaningStock Impact
CREATEDPending approvalNone
APPROVEDApproved and processedStock updated
CANCELLEDCancelled/rejectedNone

To approve or cancel:

  1. Go to Inventory → Transactions (left sidebar)
  2. Filter by Status: CREATED
  3. Click Approve or Cancel on the transaction
Requires APPROVE_TRANSACTIONS or CANCEL_TRANSACTIONS permission.

9.1 Shift Management

Before making sales, you must open a shift:

Opening a Shift

  1. Navigate to POS Terminal (left sidebar)
  2. If no shift is open, you'll be prompted to open one
  3. Enter the Opening Amount (cash in drawer)
  4. Click Open Shift

Closing a Shift

  1. Go to Sales → Shifts
  2. Count your cash and enter the Closing Amount
  3. The system calculates Expected Amount and shows any Over/Short
  4. Add optional Remarks
  5. Click Close Shift
Only ONE shift can be open per cashier at a time.

9.2 Creating a Sale

  1. In the POS terminal, use the search bar (with barcode icon) to find items
  2. Click on a product card to add it to the cart
  3. Adjust quantity using the + / − buttons in the cart
  4. The totals update automatically (Subtotal, Discount, Tax, Total)
  5. Apply a transaction-level discount if needed (No Discount / % / Fixed)
  6. Click Pay when ready

9.3 Processing Payment

  1. Select Payment Method: Cash, GCash, Bank Transfer, Credit, or Multiple
  2. Enter the Amount Tendered
  3. The system calculates Change automatically
  4. For GCash/Bank Transfer: enter the Reference Number
  5. For split payments: add multiple payment lines
  6. Click Complete Sale
Stock is automatically deducted when payment is processed (sale status changes to PAID).

Sale Status Workflow

OPEN → PAID → CLOSED

9.4 Voiding a Sale

  1. Go to Sales → Sales History
  2. Find the sale and click Void
  3. Enter a Void Reason (required)
  4. Confirm the void
Voiding a PAID or CLOSED sale reverses the stock deduction. A void reason is required and logged in the audit trail.

9.5 Receipts

Receipts can be viewed and printed for any PAID or CLOSED sale.

Receipt Contents (BIR-compliant)

  • Business name, TIN, and address
  • Receipt/OR number (sequential)
  • Date, time, and cashier name
  • Items with quantity, price, and amount
  • Subtotal, discount, VAT breakdown, total
  • Payment method, amount tendered, change

Senior Citizen / PWD Discount

Select SC/PWD discount type to apply:

  • 20% discount on applicable items
  • Automatically VAT-exempt (per Philippine law RA 9994 / RA 7277)

11.6 User Access Rights

Permissions are now managed through dynamic roles rather than a fixed preset matrix. Each role carries its own set of permissions, and users inherit permissions from their assigned role.

To create or edit roles and their permissions, go to Administration → Roles. See Section 14 — Roles & Permissions for step-by-step instructions.

To change what a user can do:

  1. Assign the user a different role in User Management, or
  2. Edit the role itself to add or remove permissions (applies to every user with that role on their next login).

14. Roles & Permissions

Roles are managed at runtime from Administration → Roles (left sidebar). Each role holds a set of permissions, and every user is assigned exactly one role. A user's effective permissions come entirely from their role — there are no per-user overrides. This area requires the Manage Users permission.

Changes to a role's permissions take effect the next time the affected user logs in (or their session token is refreshed), because permissions are carried in the login token.

Create a Role — Step by Step

Edit or Deactivate a Role

  1. On the Roles list, click the edit (✎) icon on the role's row.
  2. Adjust the name, description, or permission ticks, then click Update.

The ADMIN role (the reserved system role) cannot be edited, deactivated, or deleted. It always holds every permission. Its edit and deactivate buttons are disabled in the UI, and the server rejects any attempt to modify it.

15. FAQ & Troubleshooting

Q: How do I switch between stores?

Use the Store Selector dropdown in the top navbar. Click it and choose a different store — the system reloads store-scoped data (stock, sales, shifts, numbering) for the selected store.

Q: Why can't I see a store?

You need to be assigned access to that store by an administrator. You only see and can operate the stores assigned to your account under User Management → Store Access.

Q: Why did I land on the POS screen instead of the dashboard?

Your account is POS-focused — it has POS access but not dashboard access. In that case the system takes you directly to the POS terminal after login. This is ideal for cashiers.

Q: Can one store see another store's stock?

No. Stock is per-store — each store tracks its own quantities, sales, and shifts. However, items, categories, customers, and suppliers are shared across all stores.

Q: How do I configure user access rights?

Go to Settings → User Access Rights tab (the 6th tab). This shows a matrix of all permissions × roles.

Q: Why can't I see certain menu items?

Your user account may not have the required permissions. The left sidebar is filtered by your permissions. Contact your administrator to grant access.

Q: Why is my stock not updating after a stock-in?

Stock transactions require approval. Go to Transactions (via the left sidebar under Inventory → Transactions), find the CREATED transaction, and click Approve.

Q: Can I edit a completed sale?

No. Completed (PAID/CLOSED) sales cannot be edited. You must Void the sale and create a new one. This maintains audit integrity.

Q: Do I need a printer to use the POS?

No. The system works fully without a printer. Receipts are displayed on-screen and can be printed via the browser's print dialog when needed.

Q: What happens when I void a sale?

If the sale was PAID or CLOSED, the stock quantities are automatically restored. A void reason is required and recorded in the audit trail.

Q: How do I apply Senior Citizen / PWD discount?

In the POS terminal, select SC/PWD as the discount type. This automatically applies 20% discount and makes the sale VAT-exempt per Philippine law.

Q: What is a Z-Reading vs X-Reading?

  • Z-Reading — End-of-day sales summary (Daily Sales Report)
  • X-Reading — Per-shift sales summary (Shift Report)

Q: How do I reset a forgotten password?

An administrator can reset your password from Administration → Users → Reset Password.

Q: Can I use this on my phone?

Yes. The system is responsive and works on desktop, tablet, and mobile devices. The left sidebar collapses on mobile, and the POS terminal adapts to smaller screens.

Q: How do I navigate faster between sections?

Use the left sidebar. Menu groups expand to reveal their pages, and the group containing your current page auto-expands. Every menu item navigates instantly with no page reload.
